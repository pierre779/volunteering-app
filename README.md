# Volunteering App


## Instructions

1. Install Node.js on your computer **(IMPORTANT, THIS WILL NOT WORK WITHOUT NODE.JS)**.
    - You can look up a tutorial for this.

2. Run "**setup.bat**", it'll launch a windows terminal with spinning bar indicating that Vite is being installed.
    - **The terminal will close on its own when installation is done**.

### You're all setup!

- Run "**run_dev_server.bat**" to run the local dev server.
  
    - This will launch a terminal that will display a local URL.
    - Pasting this URL into the browser will show you the front-end.
    - Closing the terminal will close the dev server.

## Process Of Committing Changes

**You cannot push changes directly to main**
   - You have to:
       1. Create a new branch
       2. Commit all changes to that branch
       3. Make a pull request
       4. Request (at least) one collaborator to review your pull request (essentially they have to make sure your code works on their end as well)
           - **For reviewers:** You'll have to clone the specific branch to make sure it works on your end (You can look up how to do this or ask in the chat)
       5. Once the collaborator has reviewed the the pull request and has it working on their end, they can approve the request 
       6. Now you can merge the request with main!
